# Artifact manifests

This directory stores lightweight manifests and schemas for the book's measured
claims. Large logs, HLO dumps, profiles, and checkpoints should live in immutable
release or object storage and be referenced by checksum.

Validate a run manifest with `artifacts/schema.json` before labeling a result
`[measured]`. Appendix F defines the required directory layout and claim-specific
files.

Compiler-delta claims retain both matched arms under
`hlo/compiler-delta/{before,after}`, plus the raw stage files, normalization
rules, literal HLO SVG, metrics, and the runtime proof named by the comparison.
An explanatory HLO sketch in a chapter is not a measured artifact.

`artifacts/hlo-fixtures/` is separate. It retains literal HLO and DOT files for
small explanatory programs generated by `bench/hlo_feature_fixtures.py` and
`tools/capture_hlo_feature_svgs.py`. Their SVGs are real compiler output, but the
fixtures are not case-study measurements and do not carry a `[measured]` label.

No current case study has a complete validated bundle.
